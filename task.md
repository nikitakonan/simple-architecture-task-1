# 🏠 Homework #1 — TV Shows Explorer

В этом задании мы будем создавать небольшое приложение для поиска и просмотра сериалов с использованием публичного [API TVmaze](https://www.tvmaze.com/api).

## 1. Поиск шоу

Для получения списка шоу используйте API:

https://api.tvmaze.com/search/shows?q=banana

Вместо `banana` вы можете передавать любой поисковый запрос через параметр `q`.

Требования:

- Изначально приложение должно отображать пустой список и только поле поиска.
- Пользователь вводит поисковый запрос, после чего приложение получает результаты от TVmaze API.
- Фильтрацию по поисковому запросу выполняет сам API.

## 2. Список и пагинация

Отображайте полученные шоу в виде списка или карточек.

Требования:

- Добавьте пагинацию по 3 элемента на страницу.
- Пользователь должен иметь возможность переключаться между страницами результатов.

## 3. Фильтрация по жанрам

Каждый объект шоу, возвращаемый API, содержит информацию о жанрах.

Над списком шоу необходимо отображать все доступные жанры для текущей поисковой выдачи.

Требования:

- Соберите уникальные жанры из полученных результатов.
- Отобразите их в виде кликабельных тегов (chips).
- При выборе жанра список должен отфильтровываться и показывать только шоу, относящиеся к выбранному жанру.
- Предусмотрите возможность сбросить фильтр и вернуться ко всем результатам.

Пример:

Допустим, вы ищете `Murder` и получаете 10 шоу. Среди них есть детективы, комедии, драмы и приключения.

Над списком отображаются все найденные жанры. Если нажать на `Comedy`, приложение должно показать только те шоу, которые относятся к этому жанру. Например, если из 10 шоу комедийных оказалось 2, в списке останутся только они.

## 4. Дополнительные требования и рекомендации

Несколько моментов, на которые хочу обратить ваше внимание:

- **Дизайна нет!** Вы полностью свободны в выборе визуального оформления. Сейчас с AI можно очень быстро прототипировать интерфейсы, поэтому не ограничивайте себя — удивляйте нас своими крутыми дизайнами!
- **Подумайте о пользовательском опыте.** Стоит ли отправлять новый запрос на каждую напечатанную букву? Нужно ли отменять предыдущие запросы, если пользователь уже ввёл новый поисковый запрос? Как обрабатывать состояния загрузки и ошибки?
- **Более сложный challenge:** если готовы к дополнительному вызову, попробуйте реализовать работу с запросами самостоятельно, без использования `useQuery`.
